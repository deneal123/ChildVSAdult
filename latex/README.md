# LaTeX sources

Every LaTeX document for the project, organized as a matrix of
**{journal articles, conference papers} × {English, Russian}**.

## Layout

```text
latex/
  shared/                     # single source of truth for shared assets
    refs.bib                  # canonical bibliography
    figures/                  # figures from scripts/make_figures.py (EN + _ru variants)
    vendor/                   # third-party class kits (git-ignored; downloadable refs)
      ieee-tbiom/             # IEEEtran bundle (build uses MiKTeX's IEEEtran, not this)
      aaai2027/               # AAAI-27 AuthorKit (aaai2027.sty/.bst + templates)
  papers/
    journal-1-tbiom/          # Article 1 — IEEE T-BIOM (exists)
      en/main.tex             #   English submission (+ supplement.tex)
      ru/main_ru.tex          #   Russian mirror
      INFO.md                 #   T-BIOM author requirements
    journal-2/                # Article 2 — reserved (future), en/ + ru/
  conference/
    aaai-27/                  # AAAI-27 conference paper
      en/                     #   the actual AAAI submission (self-contained)
      ru/                     #   Russian mirror — NOT an AAAI submission (see ru/README.md)
```

## Building

Each paper builds from **its own directory**:

| Paper | Command (run inside the dir) |
| --- | --- |
| Journal EN | `cd papers/journal-1-tbiom/en` → `pdflatex main; bibtex main; pdflatex main; pdflatex main` |
| Journal RU | `cd papers/journal-1-tbiom/ru` → `pdflatex main_ru; bibtex main_ru; pdflatex main_ru; pdflatex main_ru` |
| Conference EN | `cd conference/aaai-27/en` → `pdflatex main; bibtex main; pdflatex main; pdflatex main` |

- **Journal papers** pull shared assets via relative paths
  (`../../../shared/figures/`, `../../../shared/refs`).
- **The AAAI conference paper is self-contained** (its own `refs.bib`, `figures/`,
  `aaai2027.sty`/`.bst`) because AAAI requires a self-contained source archive.

Figures are regenerated by `../scripts/make_figures.py` → `latex/shared/figures/`
(no experiment re-run needed; hardcoded curated-data constants).

## Notes

- `shared/vendor/` holds downloaded class kits for reference and is **git-ignored**.
  The IEEE build relies on MiKTeX's genuine IEEEtran; the AAAI build uses the
  copies committed inside `conference/aaai-27/en/`.
- `_attic/` — leftover template files from an unrelated project (git-ignored).
