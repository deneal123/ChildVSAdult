# LaTeX sources — IEEE T-BIOM submission

Two mirrored versions of the paper "Age-Invariant Identity Matching from
Naturally-Anchored Social-Media Posts":

| File | Purpose |
| --- | --- |
| `main.tex` | **English** (the submission language for IEEE T-BIOM) |
| `main_ru.tex` | **Russian** mirror (same structure, tables, figures) |
| `refs.bib` | shared bibliography (compiled with `IEEEtran.bst`) |
| `figures/` | vector PDF figures, generated by `../scripts/make_figures.py` |
| `INFO.md` | IEEE T-BIOM author requirements (reference) |
| `FormatJournal/` | the official IEEEtran bundle + author HOWTOs (reference only) |
| `_attic/` | leftover template files from an unrelated project (git-ignored) |

## Build

```
pdflatex main ; bibtex main ; pdflatex main ; pdflatex main
pdflatex main_ru ; bibtex main_ru ; pdflatex main_ru ; pdflatex main_ru
```

Compiles with MiKTeX, which auto-installs IEEEtran and the T2A Cyrillic fonts on
first run (`pdflatex --enable-installer`). The English paper is 8 pages, the
Russian mirror 9 (Cyrillic is wider); both are within the 10-page regular-paper
limit.

## Draft conventions

- **RED `[text]`** — real data the authors must still fill in before submission
  (currently: the ethics-committee name, the protocol/exemption, and the
  approval date in the Ethics section).
- **GREEN "Review note" boxes** — the assistant's editorial notes; delete them
  before submission.

## Notes

- `FormatJournal/IEEEtran.cls` and `IEEEtran.bst` in the downloaded bundle are
  corrupt (they contain changelog text, not the class/style). The build instead
  relies on MiKTeX's genuine IEEEtran package.
- Figures carry English labels in both versions; a Russian-labelled set can be
  generated from `make_figures.py` if required.
